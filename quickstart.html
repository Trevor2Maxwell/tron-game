Light Cycle Battle

Quick start for the Zoom desktop app

Install and open the game

  1. Find Light Cycle Battle in the Zoom App Marketplace.
  2. Select Install and approve the requested permissions. If you see Request pre-approve, ask your Zoom admin to approve the app.
  3. In a Zoom desktop meeting, open Apps → My Apps → Light Cycle Battle.

Host or join a round

Open the game from My Apps, choose a mode and lobby size, then start a lobby. Use Play Together to invite people in the meeting. Invited players open the prompt, choose a display name, and select Ready in the lobby.

  • Timed. Finish with the fewest crashes when time expires.
  • Elimination. Stay in the arena until you are the last player with lives remaining.
  • Use W A S D to steer. Press Space for a short boost. Hold E to ready your disc and release to throw it.

Troubleshooting

Use the desktop app if you cannot see My Apps. If you arrive in the wrong lobby, return to the current meeting and reopen the host's invitation. If your controls do not respond, click inside the game panel to give it keyboard focus.

If you still need help, visit Light Cycle Battle support.

Remove the game

Open Zoom App Marketplace, select Manage → Added Apps, find Light Cycle Battle, and select Remove. Use your Zoom Marketplace billing settings to manage a paid plan. See the privacy policy for data handling and removal.
